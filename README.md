## Subir a GitHub

```bash
git init
git add .
git commit -m "Primer commit: portafolio base"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/portafolio-web.git
git push -u origin main
```

(Reemplaza `TU-USUARIO` por tu usuario de GitHub, después de crear el repositorio vacío en github.com/new)

## Publicar gratis (GitHub Pages)

1. En el repo en GitHub: **Settings → Pages**
2. En "Source" elige la rama `main` y la carpeta `/ (root)`
3. Guarda — en un par de minutos el sitio queda en `https://TU-USUARIO.github.io/portafolio-web`
